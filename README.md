# 🌍 WorldWise

A travel tracking app where users can log the cities they’ve visited and explore them on an interactive map.

Built as part of Jonas Schmedtmann’s React course and extended into a **real-world app** using **Supabase authentication + database + React Query + TypeScript**.

## 🚀 Live Demo

https://worldwise-oraby.vercel.app/

## ⚙️ Tech Stack

- React
- TypeScript
- React Router
- React Query
- Supabase (Auth + Database)
- Leaflet (Maps)

## 🔐 Authentication

- Full user authentication system using Supabase
- Protected routes
- Persistent sessions
- Secure login/logout flow

## ✨ Features

- Add and delete visited cities
- Interactive map with markers (Leaflet)
- Save city notes and visit details
- View visited countries
- User-specific data (each user has their own cities)
- Server state management with React Query (caching, syncing, refetching)

## 🧠 Purpose

This project focuses on building a production-like frontend application with authentication, backend integration, and modern state management patterns.
